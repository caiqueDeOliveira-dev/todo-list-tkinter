# 📝 To-Do List Desktop (Tkinter)

  <img src="./screenshot.png" alt="Interface do To-Do List" width="600px" />
</p>

Uma aplicação desktop moderna e intuitiva para gerenciamento de tarefas diárias, desenvolvida em **Python** utilizando a biblioteca gráfica **Tkinter**. O sistema conta com persistência de dados local, garantindo que as suas tarefas fiquem salvas mesmo após fechar o aplicativo.

---

### 🚀 Funcionalidades

* **Adicionar Tarefas:** Insira novas pendências rapidamente através de um campo de texto de fácil acesso.
* **Remover Tarefas:** Exclua tarefas concluídas ou descartadas da sua lista com apenas um clique.
* **Persistência de Dados:** Armazenamento automático das tarefas em um arquivo de texto local (`.txt`), para que você nunca perca seu progresso ao fechar o app.
* **Interface Responsiva:** Janela limpa, centralizada e de fácil navegação.

---

### 🛠️ Tecnologias Utilizadas

* **[Python](https://www.python.org/):** Linguagem base do projeto.
* **Tkinter:** Biblioteca nativa para o desenvolvimento da interface gráfica (GUI).
* **Manipulação de Arquivos (I/O):** Lógica nativa para leitura e escrita de dados de forma local.
