# Gerenciador de Tarefas com Tkinter

Aplicação desktop desenvolvida em Python utilizando Tkinter para gerenciamento de tarefas.

## Funcionalidades

- Adicionar tarefas
- Remover tarefas
- Marcar tarefas como concluídas
- Salvar tarefas em arquivo
- Carregar tarefas automaticamente

## Tecnologias

- Python
- Tkinter

## Como executar

```bash
python main.py
