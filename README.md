# Gerenciador de Tarefas (To-Do List) em Tkinter

Uma aplicação desktop simples e eficiente, desenvolvida em Python com a biblioteca **Tkinter**, projetada para ajudar na organização de tarefas diárias com persistência de dados.

## 🚀 Funcionalidades

* **Adicionar Tarefas:** Insira novas pendências de forma rápida.
* **Remover Tarefas:** Selecione e remova tarefas concluídas ou descartadas.
* **Persistência de Dados:** O sistema salva automaticamente suas tarefas em um arquivo `tarefas.txt`. Quando você abrir o programa novamente, suas tarefas estarão lá!
* **Interface Intuitiva:** Desenvolvida com foco na simplicidade e facilidade de uso.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Interface Gráfica:** Tkinter
* **Manipulação de Arquivos:** Módulo `os` nativo do Python
